# Socle des Cocktails

Application pédagogique pour la culture professionnelle (bac pro Commercialisation et services en restauration) — Lycée Ambroise Croizat, Moûtiers.

Elle regroupe les 36 cocktails du *Socle des Cocktails de Référence* (édition 2025) :

- **Les alcools** : 12 familles classées du plus au moins utilisé, chacune avec sa présentation (carte d'identité, fabrication) et la liste de ses cocktails, ingrédients compris.
- **Les fiches techniques** : recette, verre, méthode, catégorie, type, TAV, technique pas à pas et variantes.
- **Les connaissances** : bonnes pratiques, catégories et types, familles, méthodes, verrerie, matériel, calcul du TAV (avec calculateur) et lexique.

## Modifier le contenu

Tout le contenu est dans le dossier `data/` :

- `data/cocktails.js` — les 36 fiches techniques
- `data/alcools.js` — les présentations des alcools
- `data/savoirs.js` — les connaissances, la verrerie, le matériel et le lexique

Le site est statique : aucun serveur ni installation n'est nécessaire. Il est publié avec GitHub Pages.
